上海三大才子 / THREE TALENTS
最高（张昭昊） × 司屠 × 吕德生 / EXHIBITION PROPOSAL

上海三大才子也可以有四个人。

这不是把三位艺术家的作品并排放在同一个房间里，而是把三个人多年共同生活、行动、写作、做艺术与互相影响的关系，重新变成一个正在发生的现场。

起源 / ORIGIN

有一天，最高、司屠和吕德生在石头上玩，康良给他们拍了一张照片。最高说：“咱们是上海三大才子啊。”后来吕德生问：明明康良也在，为什么不是上海四大才子？最高回答：“上海三大才子，也可以有四个人啊。”

第四个人可以是康良、策展人、观众、AI、上海，或者任何临时进入这段关系的人。

三个人 / THREE

01

最高

Highest / Zhang Zhaohao
艺术家、导演、写作者

最高，日本博士后。以“最高 / 张昭昊”持续进行行为、影像、写作、设计与跨媒介项目。2016 年起参与创建强碱艺术，曾创作实验电影《96'-House》以及多件行为作品；2020 年后在上海与司屠、吕德生展开“都市罗曼史有限公司”等共同实践。

其个人网站呈现的实践横跨行为艺术、独立电影、纯文学与设计，并持续把日常经验、文字和传播媒介转译为作品。

02

司屠

Si Tu
写作艺术家

司屠，1975 年生，写作艺术家。他长期坚持以“写作艺术家”而非“作家”自称。《今天》杂志的相关介绍强调他对语言形式与标准的持续实验，并概括其创作观为“语言就是世界观”。

除写作外，他也持续进入展览与现场艺术；文本、现成物、交换与交易常被直接转化为作品机制，使语言从纸面进入现实关系。

NAME / 命名
03

吕德生

LDS / Lyu Desheng
艺术家、行为艺术家、现场艺术组织者

吕德生，1990 年生于安徽亳州，现居上海。2013 年毕业于安徽师范大学，长期以行为、现场与即兴方式工作，并持续参与艺术项目组织。公开艺术档案将其介绍为艺术家、水泥公园项目发起人。

其实践包括《永恒的建筑》《大天门计划》《吃瓜》等行为项目；水泥公园则持续组织现场艺术节、LIVE HOUSE 与线上项目。

DO / 做

不是三件作品，而是一台机器

事件 → 吕德生行动 → 司屠命名 → 最高编辑 / 发布 → 观众反应 → 再产生事件。

三个版本

01 小型 / 7–14 天

开幕时只有一块石头、一张老照片和第四把空椅子。司屠每天产生文字，吕德生每天产生行为，最高每天把现场重新编辑成照片、录像、网页和发布物。空间从空白逐日长满。

02 大型 / 上海三大才子有限公司

把展览变成一家公司：前台、财务部、写作部、行为部、影像部、销售部、人事部。艺术、劳动、交易、友谊和身份同时成为作品。

03 线上 / 第四大才子

网站开放“第四席”。访客申请成为第四大才子，接受由三人档案和 AI 生成的行动任务，上传证据，最终形成不断扩张的共同档案。
